# Security Policy

Mongez is fully offline: it has no servers or accounts, and data stays on the device
(shared preferences, plus any backup files you export yourself).

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please **don't open a public issue** for security problems. Instead, use GitHub's
[private vulnerability reporting](https://github.com/AdamG00D/Mongez/security/advisories/new)
and include:

- what the issue is and its impact,
- steps to reproduce (device, Android version, app version),
- a suggested fix, if you have one.

You should get a reply within a week. Once a fix is released, you'll be credited unless you
prefer otherwise.
